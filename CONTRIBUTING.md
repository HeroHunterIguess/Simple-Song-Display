# Contributing
Do *not* use AI for contributing to Simple Song Display. 

Do *not* make *major* reworks to the code, unless it is necessary for another improvement/feature.

Please include all relevant information and an explanation of the changes in the pull request.

**Use the following categories for commits:**
- `feat`: A new feature
- `impr`: An improvement to an existing feature
- `fix`: A fix to a bug or something that was wrong
- `docs`: Documentation/readme changes
- `style`: Changes that do not affect the code, just comment/spacing updates
- `chore`: Changes that dont apply to any other category above

Examples:
- feat: add new feature
- chore: remove unused variable
- style: update comment
